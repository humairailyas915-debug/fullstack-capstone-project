# User Story Template

**Title:** As a user, I want to browse available gifted items so that I can find household goods I need.

**As a** registered GiftLink user,
**I want to** search and view details of items listed by others,
**So that** I can recycle household goods and save money.

### Acceptance Criteria:
1. Users can view a list of all items on the home page.
2. Users can search items by category, condition, and age.
3. Users can view detailed information for each item.
